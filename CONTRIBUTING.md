# Contributing

Thanks for helping make FileMorrow safer and smarter.

1. Create a focused branch.
2. Keep classification conservative: uncertain files belong in Needs Review.
3. Add or update tests for rule changes.
4. Run `swift test` and a release build.
5. Never add telemetry or transmit file content without an explicit,
   user-visible design discussion.

Bug reports should include macOS version, the file extension, the expected
category, and a privacy-safe filename example. Do not attach sensitive files.
